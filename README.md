  PhillCraft Base 

Базовая сборка Minecraft на NeoForge 1.21.1, оптимизированная настолько, что ФПС упирается только в лимиты самого движка. Создана как фундамент для будущих сборок. Если что-то сломалось — виноват тот, кто последний делал git push.

    [!WARNING]Сборка не тестировалась на Windows. Если ты используешь Windows, мы не гарантируем, что у тебя не сгорит блок питания от количества мусорных процессов в фоне. Переустанавливай ОС или страдай.(Java это VM и любой джава код должен работать одинаково на всех системах но ключевое слово должен поэтому от греха по дальше предупреждаем)

📂 Структура (Архитектура сборки)

Мы не просто кидаем все моды в одну кучу, у нас тут порядок, как в /etc:

    /Libs/ — Базовые библиотеки и API. Если ты удалишь отсюда хоть один файл, сборка крашнется быстрее, чем pacman -Sy без u. 
    /Optimization/ — Серверная и клиентская оптимизация. Lithium, FerriteCore и прочие алгоритмические костыли.
    /Client/ — Всякий визуальный мусор, шейдеры и интерфейсы. При деплое на сервер просто удаляем эту папку целиком: rm -rf Client/.
        /Client/Optimization/ — Sodium и его свита. Живут отдельно, чтобы не конфликтовать с серверной оптимизацией.
    /Utils/ — Утилиты (Spark, JEI/Jade-зависимости). Работают и на клиенте, и на сервере.
    /Other/ — Контент, который не вписался ни в одну другую категорию. Диагональные заборы и дурацкие бочки.

🚀 Установка и запуск

    Установи  любой нормальный Лаунчер (потому что официальный лаунчер — это Bloatware от Microsoft).


    Склонируй этот шедевр в терминал:
    
     
    git clone https://github.com/mishadudnev225-droid/mods.git
     
     
    Создай сборку в лаунчере маинкрафта, укажи NeoForge версии 21.1.241 и закинь папки внутрь .minecraft. Либо используй симлинки, если твоя система на это способна.

🔄 Как откатить изменения, если Арчюзер всё сломал

Поскольку это база, мы используем всю силу Git:
 
  
 
 
# Посмотреть, что натворил Арчюзер
git log --oneline --graph

# Жестко откатить сборку к стабильному коммиту
git reset --hard <commit_hash>
 
 
🧩 Добавление новых модов

Перед тем как добавить новый .jar, спроси себя:

    Нужен ли он на сервере?
    Это библиотека или контент?
    Не превращает ли он игру в говно?

 
 
# Правильный коммит
git add .
git commit -m "feat: added another optimization mod instead of doing university homework"
git push origin main
